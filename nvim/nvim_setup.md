# NVIM Installation

```bash
sudo apt install neovim
```

# NVIM Plugin Manager settings

Create following path and add plug.vim 

```bash
vim .local/share/nvim/site/autoload/plug.vim
```

# NVIM config file setup

Create following path and add init.vim 

```bash
vim .config/nvim/init.vim
```

# Installing Plugins

1. Open vim using following command
```bash
nvim
```

2. Type ":PlugInstall" and enter to install all plugins
